# 日语学习星图

一个跳出"背单词卡片"套路的日语学习 Web 应用，核心是三个针对真实痛点设计的模块：

- **知识星图**：按 N5→N1 分层的关联知识网络（助词 + 语法点），用探索代替打卡。红色虚线连接的是最容易混淆的一对（如 は/が、そうだ様態/伝聞、受身/使役），点开节点可查看详情并立即小练习。
- **助词专项训练**：针对易混淆助词做对比选择练习，答错时解释两者区别而不是只给答案，正确率通过间隔重复（Leitner box）驱动后续复习节奏。
- **敬语关系滑块**：拖动你和对方的社会距离，同一句话实时切换 普通体 / 丁寧語 / 尊敬語 / 謙譲語，把敬语背后的逻辑可视化。

所有学习进度保存在浏览器本地（localStorage），无需注册登录。

## 技术栈

React + TypeScript + Vite + Tailwind CSS，纯前端，无后端依赖。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
